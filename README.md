# barbershop-web

The Modern Cut & Co. — Premier Men's Barbershop & Grooming Studio Website.

Built with:
- **Next.js 16** (App Router & Turbopack)
- **React 19**
- **Tailwind CSS v4** (CSS-first `@theme` configuration)
- **TypeScript**
- **Lucide Icons**
- **Google Fonts** (Outfit & Plus Jakarta Sans via `next/font/google`)

## Features
- Clean, sunlit, warm light-theme aesthetic
- Normal sentence case typography (no all-caps)
- Transparent service menu & pricing guide
- Hairstyle gallery & lookbook with face-shape guidance
- Master barbers & craftspeople team showcase
- Direct appointment reservation system with instant WhatsApp concierge integration
- Verified Google reviews & testimonials
- Studio location, opening hours & studio amenities (Free Valet, High-Speed WiFi, Cold Brew Bar)

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) or [http://localhost:5050](http://localhost:5050) with your browser.

## Deploy on Vercel

This project is configured out-of-the-box for [Vercel](https://vercel.com). Simply import this repository into Vercel and it will automatically build and deploy.
